# Drawing Board

A simple interactive drawing board application built with Python.

## Features

- Interactive canvas for drawing
- Multiple drawing tools (pen, eraser, shapes)
- Color selection
- Save and load drawings
- Clear canvas functionality

## Requirements

- Python 3.x
- tkinter (usually comes with Python)
- PIL/Pillow

## Installation

```bash
pip install pillow
```

## Usage

Run the drawing board application:

```bash
python drawing_board.py
```

## Controls

- **Left Mouse Button**: Draw
- **Color Buttons**: Select drawing color
- **Clear Button**: Clear the canvas
- **Save Button**: Save your drawing as PNG
- **Eraser Button**: Switch to eraser mode

## Files

- `drawing_board.py` - Main application file
- `requirements.txt` - Python dependencies
